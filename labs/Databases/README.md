<h1>WHAT ARE AWS DATABASES?</h1>
<p>AWS databases are managed database services provided by Amazon Web Services (AWS) that allow you to store, manage, and retrieve data in the cloud without having to maintain the database infrastructure yourself. AWS handles tasks such as server setup, backups, scaling, security, and maintenance, so developers can focus on building applications.</p>
<h2>Main AWS database types</h2>
<p>AWS groups its databases into 8 main database types, each designed for a different kind of data and workload. These are all services offered by Amazon Web Services to help organizations store and manage data efficiently in the cloud.</p>
<h3>1. Relational databases</h3>
<p>Relational databases store data in tables with rows and columns and use SQL to manage the data</p>
<p><b>AWS Service:</b> Amazon RDS, Amazon Aurora</p>
<p><b>Examples of use:</b> Banking systems, inventory systems, customer databases</p>
<h3>2. Key-value databases</h3>
<p>A key-value database stores data as a pair of a key and its value, making it very fast for simple lookups.</p>
<p><b>AWS Service:</b> Amaozon DynamoDB</p>
<p><b>Examples of use:</b> Gaming leaderboards,Session storage for websites, Shopping cart data</p>
<h3>3. Document databases</h3>
<p>Document databases store data as documents (usually JSON) instead of tables.</p>
<p><b>AWS Service:</b>Amazon DocumentDB</p>
<p><b>Examples of use:</b> User profiles, Content management systems, Product catalogs</p>
<h3>4. In-memory databases</h3>
<p>These databases store data in RAM instead of disks, making them extremely fast.</p>
<p><b>AWS Service:</b> Amazon ElastiCache, Amazon MemoryDB for redis</p>
<p><b>Examples of use:</b> Real-time analytics, Gaming applications, Application caching</p>
<h3>5. Draph databases</h3>
<p>Graph databases focus on relationships between data, using nodes and edges.</p>
<p><b>AWS Service:</b> Amazon Neptune</p>
<p><b>Examples of use:</b> Social networks, Fraud detection, Recommendation systems</p>
<h3>6. Time-series databases</h3>
<p>Time-series databases store data that changes over time.</p>
<p><b>AWS Service: Amazon Timestream</b></p>
<p><b>Examples of use:</b>  IoT device data, Application monitoring, Sensor data tracking</p>
<h3>7. Ledger databases</h3>
<p>Ledger databases maintain a secure and immutable record of transactions.</p>
<p><b>AWS Service:</b> Amazon QLDB</p>
<p><b>Examples od use:</b> Financial transactions, Supply chain tracking, Audit records</p>
<h3>8. Data warehouse databases</h3>
<p>A data warehouse is used to analyze large amounts of historical data for reporting and business intelligence.</p>
<p><b>AWS Service:</b> Amazon Redshift</p>
<p><b>Examples of use:</b> Business reporting, Market analysis, Big data analytics</p>
