<h1>WHAT IS LINUX?</h1>
<p>Linux is an operating system that is freely distributable under the terms of the Gnu is Not Unix (GNU) General Public License (GPL). It is open source because it provides the source code for the core functionality of an operating system, called a kernel, and users can modify and expand it. As a result, many distributionsof Linux are available today.With Linux, multiple people canuse the same computer at the same time and can run multiple applications simultaneously. It also supports network functionality and provides system tools and utilities to increase usability.</p>
<h1>Amazon Linux 2</h1>
<p>Amazon Linux 2 is the latest Linux operating system that AWS offers. It is designed to provide a stable, secure, and high-performance runtime environment for applications that run on Amazon Elastic Compute Cloud (Amazon EC2). It supports the latest EC2 instance type features and includes packages that facilitate integration with AWS.Amazon Linux 2 enhances security by automatically applying critical or important security updates when an instance is booted.</p>
<h1>Linux Components:</h1>
<p><b>Kernel:</b> Core of the Operating System, manages hardware resources and provides services to applications.</p>
<p><b>System Libraries:</b> Pre-built code libraries that applications use to interact with the kernel.</p>
<p><b>System Utilities:</b> Tools for system management, like ls, cp or useradd</p>
<p><b>Shell:</b> Command line interface (CLI) for interacting with the operating system, like Bash or Zsh</p>
<p><b>User Applications:</b> Programs like web browsers, text editors, or games</p>
