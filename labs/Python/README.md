<h1>WHAT IS PYTHON?</h1>
<p>Python is a high-level, versatile programming language. It is known for its simplicity, readability, and ease of use, making it a great language
for beginners and experts alike. Its syntax is designed to be clear and concise, allowing developers to focus on solving problems rather than wrestling with code.</p>
<h1>What is python used for?</h1>
<p>PYTHON IS USED FOR:</p>
<ol>-Web development</ol>
<ol>-Data analysis</ol>
<ol>-Machine learning</ol>
<ol>-Automation</ol>
<ol>Just to name a few...</ol>
